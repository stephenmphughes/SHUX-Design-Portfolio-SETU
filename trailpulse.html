TrailPulse

A focused Irish hiking companion built with React, combining interactive maps, weather insights, and community features for better trail decisions.

Project duration: Mar ’25 – Apr ’25

Role: UX/UI design, frontend development, dashboard, authentication

Overview

A Local Hiking Companion for Ireland

TrailPulse was created to solve a simple problem: Irish hiking information is often spread across separate websites, generic apps, weather sources, review pages, and trail lists. The app brings trail browsing, mapping, live weather, reviews, tips, and community features into one focused React experience.

The project was developed as a group application, with my main contribution focused on the Landing/Home page, authentication screens, dashboard, dashboard navigation, visual styling, and the logged-in user experience.

Architecture

Stack & Architecture

TrailPulse is a React single-page app that combines client-side routing, a lightweight UI system, map rendering, live weather lookups, dashboard data visualisation, and community interaction.

  • Framework: React SPA with react-router-dom for page navigation.
  • UI Layer: Bootstrap, custom App.css, React Icons, FontAwesome, and Framer Motion.
  • Authentication: Login/Signup flow supported by a small Node.js backend.
  • Maps: Leaflet / react-leaflet with MapTiler / OSM map tiles.
  • Weather: OpenWeather API requests using Axios.
  • Dashboard Data: ArcGIS Get Ireland Active Trail Routes dataset used for difficulty and dog-friendly chart data.
  • Community: Firebase Realtime Database for dashboard forum posts and comments.
  • Visualisations: Chart.js / react-chartjs-2 wrapped in Bootstrap carousel layouts.

Outcomes

Outcomes, Learnings & Challenges

TrailPulse resulted in a working React hiking application that brought together trail content, weather checks, interactive maps, dashboard interaction, reviews, tips, and data visualisations in one connected user experience.

Outcomes
  • Built a dedicated hiking interface focused on Irish trails.
  • Connected multiple frontend features into one consistent React app.
  • Created a dashboard area with charts, forum content, and logged-in navigation.
  • Used APIs and external services to support maps, weather, and trail insights.
Learnings
  • Improved my understanding of React routing and component structure.
  • Learned how to manage frontend and backend folders separately.
  • Worked with live data sources and asynchronous API calls.
  • Gained more experience designing dashboard-style layouts and navigation.
Challenges
  • Keeping map, weather, and chart data reliable.
  • Making team-built pages feel visually consistent.
  • Balancing functionality with a simple, beginner-friendly codebase.
  • Handling API issues when external data was slow or inconsistent.
